# Cozy Tiles

Уютная онлайн-игра в плитки (числа 1–13, ряды и группы, котики-джокеры) для 2–5 друзей в браузере.
Четыре темы (дождик, ночь, осень, сакура) и лофай-музыка, которая генерируется прямо в браузере.

## Запуск

```bash
npm install
npm run dev        # сервер :3001 + клиент :5173 (с горячей перезагрузкой)
```

Открой http://localhost:5173. Друзья в той же Wi-Fi сети могут зайти по адресу, который Vite пишет как `Network`.

Продакшен-режим (один процесс отдаёт и игру, и сокеты):

```bash
npm run build
npm start          # http://localhost:3001, порт можно задать через PORT
```

## Проверки

```bash
npm test           # правила: ряды, группы, джокеры, первый выход
npm run typecheck
```

## Устройство

- `shared/rules.ts` — правила игры, общие для сервера и клиента.
- `server/` — Express + Socket.IO. Сервер хранит колоду и руки, проверяет каждый ход, ведёт таймер.
  Комнаты живут в памяти процесса, поэтому сервер должен работать в одном экземпляре.
- `src/` — React-клиент: стол и рука с drag-and-drop (мышь и палец), сцены, котики.
- `src/audio/engine.ts` — генератор лофая на Web Audio: аккорды, бас, барабаны со свингом, винил, дождь.
